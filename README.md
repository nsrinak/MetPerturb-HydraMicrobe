# Single metabolite perturbation on Host-associated microbiome

In this study, we analyzed 16s rDNA of Hydra vulgaris AEP microbiomes under different single-metabolite perturbations. We performed (I) microbial composition analysis, (II) linking of 16s rDNA and microbial genomes (metagenome-assembled genomes (MAGs) and isolated genomes), and (III) microbial community functional analysis. This repository stores neccessary data and scripts for analysis and visualization.

The Biolog 16s dataset can be derived from https://doi.org/10.1128/mbio.03843-24. 
The Hydra metagenome dataset can be derived from NCBI, under accession number: xxxxxxxx. 
The isolated genomes, and MAGs can be derived from supplementary data of this work.
